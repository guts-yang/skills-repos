# 贯穿子 Skill｜科研周会与阶段复盘

## 职责

跨 R0–R6 汇总本周期目标、证据、质量门、风险与下一步。负责简洁汇报和决策请求；不重新解释未核验数字、不粉饰失败、不代替对应阶段 Skill 完成技术分析。

## 输入

当前阶段与上次决策、本周实验/阅读/写作日志、产物链接、基线与设置、已通过/阻塞 Gate、需要导师/合作者拍板的问题。缺少数据时明确列缺口。

## 步骤

1. 对齐本周目标和当前 Stage，回看上次 Action Items 是否完成及证据位置。
2. 提炼新证据和结果，标明来源/版本/设置，并区分事实、解释、假设、待核。
3. 对照当前质量门给出 PASS / PASS_WITH_CAVEATS / BLOCKED / FAIL；说明决定依据，不用任务完成率代替科研进展。
4. 展示必要可视化：阶段流程/方法图、基线比较表或趋势图；图表标注数据来源和设置。
5. 选择下周最小可判别动作，写清预期观察、成功/失败结果分别如何改变下一步。
6. 把需要导师决策的问题写成选项、证据、影响和推荐项；不把开放式“请指导”当作问题。

## 交付模板

- 本周目标 / 当前轮次：
- 已完成及对应证据：
- 基线/实验/文献进展（含设置、差异与不确定性）：
- Gate 状态与理由：
- 当前最大风险 / 未决假设：
- 下周最小验证动作及成功/失败后的分支：
- 需要导师/合作者决策：

## 质量门与衔接

- **合格复盘：**核心结论可追溯；失败和偏差如实呈现；有明确的下一步和决策请求。
- **不合格信号：**只有忙碌事项、没有数据/图表、比较口径缺失、把建议说成实验结论。

如发现研究问题有误，指向 R3；文献覆盖缺口指向 R1/R2；比较协议问题指向 R4；复现偏差指向 R5。复盘结论形成标准交接包并保留负责人/截止时间（用户未提供时标“待定”）。
